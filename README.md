## 🛠️ 主な公開リポジトリ・制作物

### 1. [el-qr-verifier](https://github.com/m-kazuha-dev/el-qr-verifier)
**地方税統一QRコード（eL-QR）電文解析・チェックディジット検証ツール**
* **技術スタック**: C# (.NET 8) / Blazor WebAssembly
* **概要**: 地方税の帳票テストや電文不整合調査の効率化を目的に自作した検証ツール。総務省・MPN規格に基づき、モジュラス10/11計算やCRC-16（生成多項式 `0x1021`）のビット演算アルゴリズムを独自実装。
* **設計のポイント**: 機密データ保護のため、サーバー通信を行わずブラウザ内で完結する WebAssembly を採用。画面と計算ロジックを疎結合に分離し、移植性と保守性を高めています。

### 2. [employee-management-system](https://github.com/m-kazuha-dev/employee-management-system)
**従業員・給与情報管理システム基盤 (Business Employee & Payroll System)**
* **技術スタック**: PHP (Laravel) / MySQL / Docker
* **概要**: 税務・基幹システムの現場で培った「データ整合性と堅牢性」の重要性をベースに設計した業務管理基盤。
* **設計のポイント**: 単なるCRUDにとどまらず、過去履歴のエビデンス保持やデータ不整合を防ぐテーブルモデリングを意識。Dockerコンテナによる再現性の高い開発環境を構築しています。
