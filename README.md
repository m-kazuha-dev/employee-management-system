# 従業員・給与情報管理システム基盤 (Business Employee & Payroll System)

## 概要
本プロジェクトは、ミッションクリティカルな業務システムを想定した従業員・給与情報の管理アプリケーション基盤です。
単なるWeb機能（CRUD）の実装にとどまらず、実際の税務・給与業務で不可欠となる「過年度エビデンスの保持」「不整合データの発生防止」「監査耐性」といった堅牢な要件をDB設計およびアーキテクチャに落とし込んでいます。

基礎技術（Web通信規約・DBトランザクション・SQL実行機構）の挙動を深く把握するため、まずはピュアPHP/SQLにて設計・実装。現在はチーム開発の生産性向上とセキュリティ標準化を見据え、**Laravelフレームワークへのリプレイス**を進めています。

## 開発の背景・目的
現職（自治体系の業務SE）における税務・住民税基幹システムの保守運用で培った「課税・給与ドメイン知識」「データ整合性を死守する視点」をWeb・コンテナ技術と融合。地域金融機関や企業インフラにおいて、信頼性の高い社内DX推進や基幹・外部連携システムの安定稼働に貢献できる技術基盤を構築することを目標としています。

## システム構成
セキュリティと保守性を担保するため、Web/アプリケーション層とデータ層を完全分離した2層コンテナアーキテクチャを採用しています。
* **App Container:** PHP 8.2 / Apache
* **DB Container:** MySQL 8.0

## 設計における技術的・業務的なこだわり

### 1. 業務ドメイン知識を反映した高信頼なDB設計
金融・税務・労務管理に求められる監査耐性とデータ保護の観点から、以下の設計を採用しています。
* **論理削除の採用 (`employees.deleted_at`)**
  * 退職等で従業員データが無効化された場合でも、過年度の税額修正・給与計算根拠・公的照会を遡って確認（エビデンス確認）できるよう、物理削除を禁止し論理削除を採用。
* **意図的なカスケード削除の非採用 (`salaries`テーブル)**
  * 親データ（従業員）の誤操作や更新処理によって、過去の確定した給与支給履歴（＝課税・徴収・法定調書の根拠データ）が連動して連鎖消失する事故を防ぐため、あえて外部キー制約に `ON DELETE CASCADE` を設定しない堅牢設計としています。
* **文字コードの厳格化 (`utf8mb4`)**
  * 氏名・住所における異体字や特殊文字の混入によるデータ欠落・破損を防ぐため、DBおよびアプリ層全体で文字コードを統一。

### 2. 環境再現性と標準化された運用フロー
* **コンテナによる環境依存の排除 (Docker):** 開発環境と本番環境の差異によるインシデントを防ぐためコンテナ化。DNS機能によるコンテナ間名前解決（`db`）を実装。
* **GitHub Flowを意識した変更管理:** `main` ブランチへの直接編集を避け、機能単位のブランチ運用とPull Requestを通じた変更履歴の追跡性を担保。

### 3. セキュリティ対策の徹底
* **SQLインジェクション対策:** PDOのプリペアドステートメント（静的プレースホルダ）を徹底し、悪意あるクエリ実行を防止。
* **XSS（クロスサイトスクリプティング）対策:** 出力時に `htmlspecialchars` による適切なエスケープ処理を実装し、スクリプト実行を無害化。

## 今後の展望 (Laravelリプレイス計画)
本基盤をベースに、エンタープライズ開発標準への適応と開発生産性・保守性の向上を進めています。

1. **MVCアーキテクチャへの移行**
   * ビジネスロジックとプレゼンテーション層の分離（関心の分離）による保守性の向上。
2. **Laravel Sail導入による開発基盤の標準化**
   * 自前Docker構成からフレームワーク標準のSail構成へ移行し、開発者ごとのセットアップ手順を標準化。
3. **スキーマ管理と整合性制御の自動化**
   * マイグレーション機能によるDB履歴管理、およびEloquent ORM / SoftDeletesを活用した論理削除処理の標準化。

## 起動方法 (Quick Start)
1. GitHubからクローン
   ```bash
   git clone https://github.com/m-kazuha-dev/employee-management-system.git
   ```
2. Docker環境のビルドと起動
   ```bash
   docker-compose up -d --build
   ```
3. 動作確認  
   ブラウザで http://localhost:8080/ にアクセスしてください。

## システム構成/ディレクトリ構造
   ```plaintext
   business-employee-management-system/
   ├── docker/                 # インフラ環境設定 (PHP, MySQL)
   │   ├── mysql/init.sql      # DB初期化・DDL定義
   │   └── php/Dockerfile
   ├── src/                    # アプリケーションソースコード (ピュアPHP)
   └── docker-compose.yml
   ```
